# 이벤트 페이지 다국어 치환 툴

한국어 원본 HTML에서 번역 대상 텍스트만 뽑아 번역용 엑셀을 만들고, 번역된 엑셀을 되돌려
**언어별 결과 HTML을 생성**하는 단일 파일 도구입니다. 빌드도 서버도 없이 브라우저에서 바로 돌아갑니다.

**바로 쓰기 →** https://rladntls94-tech.github.io/localizer/

## 워크플로

```
한국어 원본 소스 삽입  →  번역용 엑셀 추출  →  언어별 번역  →  엑셀 적용  →  언어별 결과 생성
```

대상 언어는 `EN 영어 · DE 독일어 · FR 프랑스어 · JP 일본어` 네 개이며, 한국어가 베이스입니다.

## 핵심 성질

- **원본 마크업을 1바이트도 바꾸지 않습니다.** 태그·인라인스타일·주석·공백은 그대로 두고 텍스트 위치만 기억했다가 그 자리만 교체합니다.
- **ID + 원문 이중 검증.** 번역 엑셀을 되돌릴 때 두 값을 대조하므로, 행 순서가 바뀌어도 제자리를 찾고 원문이 훼손된 행은 조용히 반영되지 않고 리포트에 남습니다.
- **외부 라이브러리 없음.** xlsx 생성/읽기(ZIP·XML), 결과 zip 묶음까지 전부 브라우저 내장 API로 처리합니다.

## 번역용 엑셀

두 시트로 만들어집니다.

| 시트 | 내용 |
|---|---|
| 번역 안내 | 작업 방법, 금지 사항, 열 설명, 표시 범례, 길이 주의, 현재 진행 상태 |
| 번역 | `ID · 구역 · 표시 · 원문(KR) · 글자수 · 유지요소 · 문맥` + 언어 열 |

- 언어 열만 편집 가능하도록 시트 보호가 걸려 나갑니다(비밀번호 없음). ID·원문을 실수로 지워 되돌리기가 깨지는 사고를 막습니다.
- 틀고정이 원문 열까지 걸려 있어 옆으로 스크롤해도 ID·원문이 남습니다.
- `유지요소`는 번역 후에도 그대로 남아야 하는 숫자·HTML 엔티티·라틴 토큰입니다.
- 지역수정 행은 보라, 삭제표시 행은 분홍 배경으로 구분됩니다.

## 되돌린 뒤 검수

엑셀 적용 직후 아래를 자동으로 잡아 경고합니다. 차단하지 않고 알려주기만 합니다.

| 검사 | 내용 |
|---|---|
| 한글 잔존 | 번역문에 한국어가 그대로 남음 |
| 숫자 누락 | 원문에 있던 숫자가 번역문에 없음 |
| 기호 누락 | 원문에 있던 HTML 엔티티가 사라짐 |
| 태그 섞임 | 번역문에 태그나 잘못된 `&`가 들어감 |
| 길이 이상 | 원문 대비 3.5배 초과 또는 1/3 미만 |

## 오프라인으로 쓰기

`localizer.html` 하나만 내려받아 브라우저로 열면 됩니다. 작업 내용은 브라우저에 자동 저장되며,
`프로젝트` 탭에서 JSON으로 백업할 수 있습니다.
