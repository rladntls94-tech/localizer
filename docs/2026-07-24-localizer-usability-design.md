# 다국어 치환 툴 사용성 개선 설계

작성일: 2026-07-24
대상 파일: `localizer.html` (단일 HTML, 외부 의존성 없음)

## 목표 워크플로

한국어 베이스 소스 삽입 → 번역용 엑셀 추출 → 언어별 번역 → 엑셀 회신·적용 → 언어별 HTML 치환

## 언어 세트

`EN(영어) · DE(독일어) · FR(프랑스어) · JP(일본어)` 네 개 고정. 한국어는 원본 소스 자체이므로 별도 탭을 두지 않는다.
기존 기본값 `ZH-TW`는 제거한다. 저장된 프로젝트에 번역 데이터가 남아있는 다른 언어가 있으면 지우지 않고
「언어 관리」에 정리 버튼으로만 노출한다(조용한 데이터 삭제 금지).

## 1. 번역용 엑셀 템플릿

한 파일 / 두 시트.

### 시트① 「번역 안내」

작업 방법, 금지 사항, 열 설명, 표시 범례, 길이 주의, 현재 상태(총 항목 수·언어별 잔여)를 담는다.
CSV로 저장할 경우 반드시 「번역」 시트를 선택한 상태에서 저장해야 한다는 경고를 포함한다.

### 시트② 「번역」

| A | B | C | D | E | F | G | H~K |
|---|---|---|---|---|---|---|---|
| ID | 구역 | 표시 | 원문(KR) | 글자수 | 유지요소 | 문맥 | EN / DE / FR / JP |

- A~G 잠금, H~K만 편집 가능 (시트 보호, 비밀번호 없음). 필터·정렬·열너비 조절은 허용.
- 틀고정 `xSplit=4 ySplit=1` — 옆으로 스크롤해도 ID·원문이 남는다.
- 유지요소 = 원문 안의 숫자 · HTML 엔티티 · 라틴 토큰. 번역 후에도 그대로 남아야 하는 값.
- 행 배경: 지역수정 = 연보라, 삭제표시 = 연분홍.
- 언어 열 헤더는 고정 열 헤더와 다른 색.

### 되돌리기(가져오기) 대응

- **시트 선택**: 시트가 2개가 되므로 워크북의 첫 시트를 무조건 읽으면 안내 시트를 표로 오인한다.
  시트명 `번역`을 우선 시도하고, 실패하면 각 시트를 순회하며 `ID`+`원문` 헤더가 잡히는 첫 시트를 쓴다.
  `applyTable`은 헤더 검증에서 던지고 그 전에는 상태를 건드리지 않으므로 순회 재시도가 안전하다.
- **언어 열 인식**: 헤더가 `EN (영어)` 형태가 되므로 괄호 주석을 떼어내는 `langFromHeader()`를 추가한다.
  기존 `번역(EN)` 형식과 순수 코드(`ZH-TW`)도 계속 인식한다.
- `XL_FIXED`에 `글자수`, `유지요소`를 추가해 언어 열로 오인되지 않게 한다.

## 2. 되돌린 뒤 검수(QA)

ID 대조만으로는 잡히지 않는, 번역 내용 자체의 사고를 잡는다. 경고일 뿐 차단하지 않는다.

| 코드 | 검사 |
|---|---|
| `kr` | 번역문에 한글이 그대로 남음 |
| `num` | 원문에 있던 숫자가 번역문에 없음 |
| `ent` | 원문에 있던 HTML 엔티티가 번역문에 없음 |
| `len` | 원문 대비 3.5배 초과 또는 1/3 미만 (원문 6자 이상일 때만) |
| `tag` | 번역문에 `<` 태그나 잘못된 `&`가 섞임 (기존 `badTr`) |

번역 테이블 툴바에 「검수 필요만」 필터와 유형별 개수 요약을 붙이고, 각 행에 해당 경고 칩을 표시한다.

## 3. 화면 사용성

- **언어 진행률 카드** — 4개 언어의 진행률을 한 화면에. 카드 클릭으로 언어 전환(기존 언어 탭 대체).
- **[전체 언어 생성]** — 4개 언어 결과를 `.txt`로 만들어 zip 하나로 내려받는다. 기존 xlsx용 `zip()` 재사용.
  개별 다운로드도 `.html` → `.txt`로 변경. 파일명 접두어는 입력 가능하게 하고 프로젝트에 저장한다.
- **스텝 완료 표시** — 헤더 스텝 버튼에 완료 여부를 표시해 다음에 할 일이 보이게 한다.
- **자동 저장 실패 경고** — 현재 `catch(e){}`로 묻히는 localStorage 실패를 상단 배너로 드러낸다.
  원본 HTML이 크면 실제로 용량을 넘길 수 있고, 그러면 새로고침 시 작업이 사라진다.
- **자동 정렬** — 기능은 유지하되 한 단계 더 접어 두고 추측 기반임을 명시한다. 정식 경로는 엑셀 왕복이다.

## 유지하는 것

추출기(`extract`)·재조립(`build`)·정렬(`align`)·프로젝트 저장 형식은 건드리지 않는다.
태그·스타일·주석·공백을 1바이트도 바꾸지 않는다는 성질이 이 툴의 핵심이다.
